# gendive-skills-common (공통 사무)

국내 사무직이 업무에서 바로 쓰는 AI 스킬 모음입니다. 개인정보 가리기, 엑셀 정리, 메모를 표로 바꾸기, 보고 숫자 검증, 그래프 만들기 5가지를 다룹니다. (스킬: AI에게 "이 업무는 이런 순서와 기준으로 해 달라"고 미리 알려 두는 지침 파일)

## 스킬 목록

| 폴더명 | 한국어 이름 | 하는 일 | 이렇게 말하면 작동 |
|---|---|---|---|
| `data-masking` | 개인정보·기밀 마스킹 | AI에 올리기 전에 내 PC 엑셀에서 개인정보를 가리는 수식과 열별 처리표를 만들어 줍니다 | "개인정보 가려줘", "마스킹 수식 만들어줘", "이 파일 AI에 올려도 돼?" |
| `excel-cleanup` | 엑셀 정리 | 병합 셀, 소계 행, 원·천원 혼재, 날짜·품목명 불일치를 정리하고 전후 합계를 맞춥니다 | "엑셀 정리해줘", "날짜 형식 통일해줘", "품목명 맞춰줘" |
| `text-to-table` | 메모를 표로 | 작업일지·정비 메모·거래명세서·대화 내용을 엑셀 표로 바꿉니다 | "작업일지 표로 만들어줘", "거래명세서 엑셀로" |
| `report-qa` | 보고 숫자 검증 | 보고 전에 합계·기간·부가세·평균·그래프를 점검해 보고 가능 여부를 판정합니다 | "보고 전에 숫자 검토해줘", "증감률 맞게 계산했는지 봐줘" |
| `chart-dashboard` | 그래프·대시보드 | 목적에 맞는 차트를 고르고 엑셀 차트 또는 HTML 대시보드로 만듭니다 | "그래프 만들어줘", "대시보드로 보여줘" |

## 쓰는 법 3가지

1. **Claude (무료 포함)**: 설정 → 기능에서 "코드 실행 및 파일 생성"을 켭니다. `skills/<스킬이름>` 폴더(예: `skills/data-masking`)를 zip으로 묶어 설정 → 스킬에서 업로드합니다.
2. **Claude Code / Cowork**: `/plugin marketplace add dorkman43/gendive-skills-common` 를 입력한 뒤 플러그인을 설치합니다.
3. **ChatGPT·Gemini**: `SKILL.md`의 맨 위 머리말(`---` 두 줄 사이)을 뺀 본문을 프로젝트 지침(ChatGPT) 또는 대화 첫 메시지에 붙여 넣고 파일을 올립니다. 각 서비스의 지침 글자 수 한도는 사용 전에 확인하세요.

## 실습용 가상 데이터

`samples/` 폴더에 연습용 파일이 있습니다. 전부 가상 데이터이며, 파일별 함정과 검산용 정답은 `samples/README.md`에 있습니다.

| 파일 | 연습할 스킬 |
|---|---|
| `고객_방문이력_원본.xlsx` | `data-masking` |
| `매입내역_정리전.xlsx` | `excel-cleanup`, `report-qa`, `chart-dashboard` |
| `작업일지_메모.txt` | `text-to-table` |

같은 파일을 다시 만들려면 저장소 폴더의 터미널(명령 입력창)에서 `python3 samples/make_samples.py` 를 실행합니다(openpyxl 필요).

## 꼭 지켜 주세요

- **실제 회사 데이터를 무료·개인용 AI 계정에 올리지 마세요.** 개인용 계정은 입력 내용이 AI 학습에 쓰일 수 있습니다. 회사가 승인한 도구인지, 학습에 쓰이지 않는 기업용 계약인지 먼저 확인하세요.
- 주민등록번호·계좌번호·비밀번호는 어떤 AI에도 입력하지 않습니다(개인정보보호위원회 이용자 가이드).
- 회사 보안 규정이 이 저장소의 안내보다 우선합니다.
- 스킬의 판정 기준과 마스킹 표기는 출발점입니다. 회사 기준이 있으면 그것으로 바꿔 쓰세요. 법률 자문이 아닙니다.
- 참고한 원본과 라이선스는 `THIRD_PARTY.md`를 보세요.
